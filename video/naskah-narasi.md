# Naskah narasi video demo — RisetKita (Open Agentic Web Challenge)

> **Penting (aturan Devpost):** video harus menampilkan **Erwin sendiri yang
> menjelaskan proyeknya**, bukan suara AI. Rekam suara ini dengan suaramu
> sendiri di HP, lalu gabungkan dengan rekaman layar (`demo-risetku.mp4`).
> Durasi total video **di bawah 2 menit** (target ~100 detik).

## Naskah (baca santai, ~95 detik)

> Halo, saya Erwin. Ini RisetKita — website agen riset berbahasa Indonesia yang
> saya buat untuk Open Agentic Web Challenge.
>
> Di sini saya ketik topik, misalnya sejarah Jakarta. Agennya langsung mencari
> dan membaca Wikipedia bahasa Indonesia, lalu menyusun brief riset singkat
> lengkap dengan sumbernya.
>
> Brief ini bisa saya simpan ke perpustakaan di browser — tersimpan di
> perangkat saya sendiri, tidak dikirim ke server mana pun.
>
> Agen ini juga bisa memeriksa fakta. Saya tanya apakah benar Jakarta didirikan
> tahun 1527 — sebelum menghubungi situs pemeriksa fakta, saya diminta izin
> dulu lewat kartu persetujuan ini. Hasilnya: didukung, dengan kutipan dari
> Wikipedia.
>
> Semua agen berjalan di browser, memakai model AI gratis, dan file jaringan
> agennya terbuka untuk umum sehingga situs agen lain bisa memanggilnya.
>
> Terima kasih sudah menonton — link situs dan kodenya ada di deskripsi.

## Cara merekam (HP saja)

1. **Rekaman layar** sudah disiapkan: `video/demo-risetku.mp4` (1280×800,
   ~90 detik, tanpa suara). Unduh file itu dari repo GitHub
   (`Erwinsp27/risetku` → folder `video/` → `demo-risetku.mp4`).
2. **Rekam suaramu** membaca naskah di atas dengan aplikasi perekam suara HP
   (atau langsung di CapCut, tombol "Voiceover"). Baca santai; tidak perlu
   sempurna — satu kali rekaman cukup. Kalau salah ucap, ulangi kalimat itu
   saja, nanti potong bagian yang salah.
3. **Gabungkan di CapCut (gratis, di HP):**
   - Proyek baru → pilih `demo-risetku.mp4` sebagai video utama.
   - Audio → Voiceover → rekam sambil memutar video, atau Audio → Extracted/
     impor file rekaman suara → taruh di timeline, ratakan dengan adegan.
   - Potong ujung video/suara supaya total **di bawah 2:00**.
   - Tambahkan teks judul di awal: "RisetKita — Agen Riset Bahasa Indonesia".
   - Ekspor 1080p, 30 fps.
4. **Buat channel YouTube** (kalau belum ada): buka aplikasi YouTube → foto
   profil → "Buat channel" → beri nama (mis. "Erwin — RisetKita").
5. **Upload video**: YouTube → tombol `+` → Upload video → pilih file hasil
   CapCut → judul: `RisetKita — Agen Riset Bahasa Indonesia (Open Agentic Web
   Challenge)` → visibilitas **Publik** → Upload.
6. **Salin link video** (Bagikan → Salin link) — link ini yang dimasukkan ke
   form submit Devpost.

## Yang TIDAK boleh di video

- Jangan pakai musik berhak cipta (musik pop, lagu orang lain). Tanpa musik
  lebih aman.
- Jangan pakai logo/merek orang lain (mis. logo Cognizant, Devpost, Wikipedia)
  sebagai hiasan — menyebut nama proyek dan situsnya dengan kata-kata boleh.
- Jangan pakai suara AI/Text-to-Speech — harus suara Erwin sendiri.
